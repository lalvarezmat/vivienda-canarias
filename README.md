# La vivienda en Canarias: la tormenta perfecta

Versión web, con gráficas interactivas, del artículo de Luis Álvarez León (ULPGC) sobre las causas de la crisis
de la vivienda en Canarias, con datos oficiales (INE, Eurostat, ISTAC, Ministerio de Vivienda y Agenda Urbana,
Colegio de Registradores).

Leer en: https://lalvarezmat.github.io/vivienda-canarias/
